1Now Booking Widget

One script tag turns any website into a company-scoped booking entry point.

Live demo

Dynamic: append ?company_id=605 (and optionally &api_url=… / &booking_url=…) to this page's URL to demo any company or environment. With nothing set it uses the test defaults above.

Add it to your site

<div id="onenow-booking-engine"></div>
<script
  src="https://cdn.1now.ai/booking-widget/v1/widget.js"
  data-company-id="YOUR_COMPANY_ID"
  data-booking-url="https://book.1now.app"
  data-target="onenow-booking-engine"
  defer></script>

Optional: data-mode="modal"|"full", data-booking-path, data-title, data-show-fleet="true", data-target-blank="true".
